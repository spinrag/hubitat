# Security

## Reporting a vulnerability

Please don't open a public issue, pull request or discussion for a security problem. Report it privately through GitHub private vulnerability reporting: open this repository's **Security** tab and click **Report a vulnerability**. We reply within a few working days and coordinate a fix and release with you.

Examples: a way to read, keep, replay or change a door code you shouldn't; a way to use or recover an app token; codes, tokens or credentials appearing in logs, pages or responses.

## What we keep private

These apps manage door codes on real locks. Public issues, pull requests, commit messages, release notes and READMEs therefore describe *what changes for users*, not how the protections work in detail. Security analysis, edge cases, review findings and known limitations are tracked privately.

## Supported versions

Only the latest release of each app in Hubitat Package Manager gets fixes. Keep HPM auto-update on for the SignalBricks apps.
